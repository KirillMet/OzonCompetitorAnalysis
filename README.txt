# Инструкция по анализу карточек товаров Ozon / Wildberries

## Шаг 1. Подготовка ссылок

Откройте файл **urls.txt**.

Вставьте в него ссылки на изображения карточек товара.

Рекомендуется соблюдать следующий порядок:

Каждая ссылка должна находиться на отдельной строке.

---

## Шаг 2. Скачать изображения

Запустите:

```text
main.py
```

Программа автоматически:

* прочитает ссылки из `urls.txt`;
* скачает все изображения;
* сохранит их в папку `downloads`.

---

## Шаг 3. Распознать текст (OCR)

Запустите:

```text
ocr_paddle.py
```

Программа:

* обработает все изображения;
* распознает текст с помощью PaddleOCR;
* сохранит результат в файл:

```text
result.txt
```

---

ПОВТОРИТЬ ПО КАЖДОЙ НОВОЙ КАРТОЧКЕ ТОВАРА 1-3


## Шаг 4. Подготовить запрос для ChatGPT

Откройте файл:

```text
prompt.txt
```

В нем уже находится готовый промпт для анализа карточек.

Откройте файл:

```text
result.txt
```

Скопируйте из него OCR-текст.

Вставьте его в соответствующие места промпта:

* OCR моей карточки;
* OCR конкурента 1;
* OCR конкурента 2;
* при необходимости других конкурентов.

---

## Шаг 5. Отправить запрос

Скопируйте полностью подготовленный промпт.

Откройте ChatGPT.

Вставьте промпт и отправьте его.

---

## Шаг 6. Получить результат анализа

ChatGPT автоматически:

* исправит ошибки OCR;
* восстановит слова по контексту;
* проанализирует каждую карточку;
* определит сильные и слабые стороны;
* сравнит карточки между собой;
* построит сравнительную таблицу;
* предложит улучшения.

В результате вы получите:

* сравнительную таблицу по всем ключевым факторам;
* ТОП рекомендаций по улучшению карточки;
* предложения по изменению отдельных слайдов;
* рекомендации по первому изображению;
* преимущества конкурентов, которые стоит использовать;
* идеи, которые помогут сделать карточку сильнее.

---

## Рекомендуемый порядок работы

1. Заполнить `urls.txt`.
2. Запустить `main.py`.
3. Запустить `ocr_paddle.py`.
4. Открыть `result.txt`.
5. Скопировать OCR-текст.
6. Вставить его в `prompt.txt`.
7. Отправить запрос в ChatGPT.
8. Получить готовый анализ карточек.
