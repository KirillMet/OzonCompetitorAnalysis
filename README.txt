# Ozon/Wildberries AI Analyzer

## Автоматический анализ карточек товаров маркетплейсов через OCR и GPT

---

# 1. Описание программы

## Назначение

Программа предназначена для автоматического анализа карточек товаров на маркетплейсах Ozon и Wildberries.

Основная задача программы:

- получить изображения карточек товаров;
- распознать текст со слайдов;
- сравнить собственный товар с товарами конкурентов;
- определить отсутствующую информацию;
- получить рекомендации по улучшению карточки;
- автоматически сформировать Excel-отчет;
- сохранить архив всех результатов выполнения.

Программа работает полностью автоматически через последовательный pipeline.

# 3. Подробное описание этапов работы


# Этап 1. Получение входных данных

Пользователь предоставляет файл:


input/links.txt


В файле находятся:

- SKU товара;
- ссылки на изображения карточки товара.

Правила:

Первый SKU считается:


Наш товар


Все следующие SKU считаются:


Конкуренты


Пример:


2842506696
https://image1.jpg
https://image2.jpg
https://image3.jpg

3517464815
https://image1.jpg
https://image2.jpg


Правила обработки:

- строка без `http` считается SKU;
- строки с `http` считаются ссылками;
- порядок ссылок сохраняется как порядок слайдов карточки.

---

# Этап 2. Парсинг ссылок

Модуль:


parser/link_parser.py


Назначение:

Получение структуры товаров из входного файла.

Задачи:

- открыть `links.txt`;
- определить SKU;
- определить принадлежность товара;
- собрать изображения каждого товара;
- сохранить порядок слайдов.

Результат:


{
SKU:
[
image1,
image2,
image3
]
}


---

# Этап 3. Скачивание изображений

Модуль:


downloader/image_downloader.py


Назначение:

Загрузка изображений карточек.

Задачи:

- скачать изображения;
- создать отдельную папку для каждого SKU;
- сохранить порядок слайдов.

Результат:


data/images/

2842506696/

01.jpg
02.jpg
03.jpg

3517464815/

01.jpg
02.jpg


Где:

- папка SKU — отдельная карточка товара;
- номер файла — номер слайда.

---

# Этап 4. Распознавание текста OCR

Модуль:


ocr/ocr_processor.py


Используемая технология:


PaddleOCR


Назначение:

Получение текста со слайдов карточки.

Задачи:

- открыть изображения;
- распознать текст;
- сохранить каждый слайд отдельно.

Результат:


data/ocr/

2842506696/

01.txt
02.txt
03.txt


Каждый TXT-файл соответствует одному изображению.

---

# Этап 5. Формирование AI-промпта

Модуль:


prompt_builder/builder.py


Использует шаблон:


prompts/prompt_template.txt


Назначение:

Создание полного запроса для GPT.

Задачи:

- загрузить пользовательский промпт;
- добавить OCR всех товаров;
- сформировать итоговый запрос.

Результат:


prompt_final.txt


---

# Использование собственного промпта

Пользователь может самостоятельно менять логику анализа без изменения Python-кода.

Файл:


prompts/prompt_template.txt


Можно изменять:

- правила анализа;
- формат JSON;
- структуру сравнения;
- требования к рекомендациям;
- формат результата.

Пример:


Ты эксперт по анализу карточек товаров.

Сравни товары конкурентов.

Верни JSON.

Данные товаров:

{PRODUCT_DATA}


ВАЖНО:

В шаблоне обязательно должна присутствовать переменная:


{PRODUCT_DATA}


Она автоматически заменяется OCR-данными карточек товаров.

---

# Этап 6. Анализ GPT

Модуль:


ai/gpt_request.py


Назначение:

Отправка запроса в GPT API.

Задачи:

- открыть `prompt_final.txt`;
- отправить запрос;
- получить ответ;
- сохранить результат.

Результат:


response.txt


---

# Этап 7. Извлечение JSON

После получения ответа GPT программа выполняет обработку:

- поиск JSON внутри ответа;
- проверка структуры;
- сохранение корректного JSON.

Результат:


response.json


Пример:

```json
{
    "products": [
        {
            "sku": "123456",
            "role": "Наш товар",
            "description": "",
            "missing_vs_our_product": []
        }
    ]
}

Если JSON отсутствует:

сохраняется исходный ответ;
создание Excel пропускается.
Этап 8. Создание Excel

Модуль:

excel_creator/excel_generator.py

Назначение:

Создание итогового отчета.

Задачи:

загрузить response.json;
создать таблицу;
автоматически создать столбцы;
применить форматирование;
сохранить Excel.

Результат:

analysis.xlsx

Excel содержит:

SKU;
роль товара;
описание карточки;
отсутствующую информацию;
рекомендации.

Дополнительно:

перенос текста во всех ячейках;
выравнивание текста;
настройка ширины колонок.
Этап 9. Архивация результатов

Модуль:

result_creator/result_exporter.py

Назначение:

Сохранение результатов каждого запуска программы.

Файлы не перемещаются, а копируются.

Это позволяет:

сохранять историю запусков;
сравнивать разные версии промптов;
анализировать ошибки;
восстанавливать предыдущие результаты.

После завершения pipeline создается папка:

RESULT

Внутри создается папка с датой и временем запуска.

Пример:

RESULT/

2026-07-24_20-30-15/

    1_resultOCR.txt
    2_prompt_final.txt
    3_response.txt
    4_analysis.xlsx
Сохраняемые файлы
1_resultOCR.txt

Копия:

result.txt

Содержит:

OCR-текст карточек;
распознанную информацию со слайдов.
2_prompt_final.txt

Копия:

prompt_final.txt

Содержит:

полный запрос, отправленный GPT;
используемый промпт;
OCR-данные.
3_response.txt

Копия:

response.txt

Содержит:

полный ответ GPT;
исходный результат AI.
4_analysis.xlsx

Копия:

analysis.xlsx

Содержит:

итоговый Excel-анализ.
