# Инструкция по использованию программы анализа карточек товаров Ozon/Wildberries

## 1. Назначение программы

Программа предназначена для автоматического анализа карточек товаров на маркетплейсах Ozon и Wildberries.

Она выполняет следующий процесс:

1. Получает ссылки на изображения карточек товаров.
2. Разделяет товары по SKU.
3. Скачивает изображения карточек.
4. Распознает текст с изображений через OCR.
5. Формирует единый промпт для AI-анализа.
6. Отправляет данные в GPT.
7. Получает рекомендации по улучшению карточки товара.

Первый SKU в файле со ссылками считается **нашим товаром**.

Все следующие SKU считаются **товарами конкурентов**.

---

# 2. Подготовка входных данных

Перед запуском необходимо заполнить файл:

```
input/links.txt
```

Формат файла:

```
МОЙ_SKU
ссылка_на_первое_изображение
ссылка_на_второе_изображение
ссылка_на_третье_изображение


SKU_КОНКУРЕНТА_1
ссылка_на_первое_изображение
ссылка_на_второе_изображение


SKU_КОНКУРЕНТА_2
ссылка_на_первое_изображение
ссылка_на_второе_изображение
```

Пример:

```
123456789
https://...
https://...
https://...

987654321
https://...
https://...
```

Правила:

* строка без `http` считается SKU;
* строки с `http` считаются ссылками на изображения;
* первый SKU — собственный товар;
* остальные SKU — конкуренты;
* порядок ссылок сохраняется как порядок слайдов карточки.

---

# 4. Этапы работы программы

## Этап 1. Парсинг ссылок

Файл:

```
parser/link_parser.py
```

Задача:

* прочитать `input/links.txt`;
* определить SKU;
* собрать список изображений каждого товара;
* сохранить порядок слайдов.

Пример результата:

```
SKU 123456:

01.jpg
02.jpg
03.jpg


SKU 987654:

01.jpg
02.jpg
```

---

# Этап 2. Скачивание изображений

Файл:

```
downloader/image_downloader.py
```

Задача:

* скачать все изображения;
* создать отдельную папку для каждого SKU;
* сохранить порядок слайдов.

Результат:

```
data/images/

123456/
    01.jpg
    02.jpg
    03.jpg


987654/
    01.jpg
    02.jpg
```

Где:

* папка SKU — отдельная карточка товара;
* номер файла — номер слайда.

---

# Этап 3. Распознавание текста OCR

Файл:

```
ocr/ocr_processor.py
```

Использует:

```
PaddleOCR
```

Задача:

* открыть каждое изображение;
* распознать текст;
* сохранить результат каждого слайда отдельно.

Результат:

```
data/ocr/

123456/
    01.txt
    02.txt
    03.txt


987654/
    01.txt
    02.txt
```

Пример:

```
01.jpg
```

становится:

```
01.txt
```

с распознанным текстом.

---

# Этап 4. Формирование промпта

Файлы:

```
prompt_builder/builder.py
```

Шаблон:

```
prompts/prompt_template.txt
```

Задача:

* загрузить шаблон анализа;
* добавить OCR-текст всех карточек;
* сохранить готовый запрос для GPT.

Результат:

```
prompt_final.txt
```

Внутри:

```
МОЙ ТОВАР SKU XXXXX

--- СЛАЙД 01 ---
текст OCR

--- СЛАЙД 02 ---
текст OCR


КОНКУРЕНТ SKU XXXXX

--- СЛАЙД 01 ---
текст OCR
```

Порядок сохраняется:

1. мой товар;
2. конкурент 1;
3. конкурент 2.

---

# Этап 5. AI-анализ

Файл:

```
ai/gpt_request.py
```

Задача:

* открыть `prompt_final.txt`;
* отправить запрос через API;
* получить анализ;
* сохранить ответ.

Результат:

```
response.txt
```

В этом файле находится готовый анализ:

* сравнение карточек;
* сильные и слабые стороны;
* рекомендации;
* новые варианты текстов;
* идеи для улучшения слайдов.

---

# 5. Описание всех Python файлов

## main.py

Главный управляющий файл.

Отвечает за последовательный запуск:

1. Парсер.
2. Загрузка изображений.
3. OCR.
4. Создание промта.
5. GPT-анализ.

Запускается пользователем.

---

## parser/link_parser.py

Парсер входного файла.

Отвечает за:

* чтение SKU;
* поиск ссылок;
* группировку изображений по товарам.

---

## downloader/image_downloader.py

Загрузчик изображений.

Отвечает за:

* скачивание картинок;
* создание папок SKU;
* сохранение изображений.

---

## ocr/ocr_processor.py

Модуль распознавания текста.

Отвечает за:

* обработку изображений;
* запуск PaddleOCR;
* сохранение текста каждого слайда.

---

## prompt_builder/builder.py

Создание AI-запроса.

Отвечает за:

* сбор OCR-текста;
* разделение товаров;
* вставку данных в шаблон.

---

## ai/gpt_request.py

Работа с AI API.

Отвечает за:

* отправку промта;
* получение ответа;
* сохранение результата.

---

# 7. Полный рабочий цикл

```
links.txt

↓

parser

↓

data/images

↓

OCR

↓

data/ocr

↓

prompt_builder

↓

prompt_final.txt

↓

GPT

↓

response.txt
```

После завершения работы файл:

```
response.txt
```

содержит готовый маркетинговый анализ карточки товара и рекомендации по улучшению.
